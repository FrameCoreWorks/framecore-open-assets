# UI SFX (CC0 interface sounds)

Sources: [repository](https://github.com/romainsimon/uisfx), LICENSE-AUDIO and `docs/taxonomy.md` at commit `9950fe66f993a6660dab9c2651dcbcd899ffd83b` (pinned). Read 2026-11-12.

78 semantic UI cues (hover, press, success, error, toggle, open, loading and so on) in 12 sound packs (minimal, soft, glass, arcade, mechanical, organic, dreamy, scifi, rubber, cinematic, studio, zen), as MP3 and OGG. The code is MIT; the audio is "dedicated to the public domain under CC0 1.0", commercial use allowed, attribution appreciated but not required. The audio is procedurally generated (not recordings). The repository was created in July 2026, so it is new and unproven; the module reads only the pinned commit.

No account or key. One request reads the taxonomy table for cue names and their use; each cue exists in every pack at `packages/uisfx/sounds/{pack}/{cue}.mp3`. A pack name in the query moves that pack's file to the front of the variants. Notes: whooshes, risers and impacts are not covered by this set.
