# Adbertiser SFX (CC0 sound effects for reels)

Sources: [repository](https://github.com/Reodelbasalan/adbertiser-sfx) (README, LICENSE, `catalog.json`, `generator/`) at commit `ed6482ebd9c1283db4ee11b69dba3426c7dd5046` (pinned). Read 2026-11-18.

408 sound effects in 30 categories aimed at Reels, TikTok, Shorts and ads: whooshes, swishes, transitions, risers, impacts, cinematic hits, glitches, typing, UI, pops, dings, alerts, camera, cash register and money, magic, cartoon, retro 8-bit, stingers, paper, foley and short nature ambience beds. CC0 1.0: commercial use, no credit required. Per the README every sound is synthesised from the repository's own generator code; nothing is sampled. WAV, 48 kHz, 16-bit, peaks at or below -1 dBTP.

No account or key. One request reads `catalog.json` (name, category, file, duration, channels, tags, description). Query words are matched against those fields; a record whose name starts with a query word ranks first. Each record is one WAV. Risk: the repository is new (November 2026) and has no track record, so the module reads only the reviewed commit; check a sound by ear before a client delivery.
