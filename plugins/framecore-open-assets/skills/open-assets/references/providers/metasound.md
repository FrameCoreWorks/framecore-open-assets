# Meta Open Sound: Oculus Audio Pack 1

Sources: [repository](https://github.com/facebookincubator/Meta-open-sound), [pack README](https://github.com/facebookincubator/Meta-open-sound/blob/251c0be57d5d1b3242b91f53e0cde62ab1cb42d9/corpora/oculus-audio-pack/README.md), ATTRIBUTION.md in the same folder. Pinned to commit `251c0be57d5d1b3242b91f53e0cde62ab1cb42d9`. Read 2026-11-12.

289 game and VR sound effects from the 2015 Oculus Audio Pack (footsteps, UI sets, vocals, doors, ambience, stings), CC BY 4.0, commercial use allowed, with a fixed credit line that the records carry: "Oculus Audio Pack 01" by Oculus VR, LLC (https://developers.meta.com/vr/downloads/package/oculus-audio-pack-1/), licensed under CC BY 4.0. The same repository's CC0 instrument packs (piano, guitars) are not part of this module.

No account or key. One request reads `manifest.json` (UCS file names and durations); query words are matched against the camel-case names, for example `UIAlert_CasualMusicalError_OS_01`. Playable files are the OGG previews (`ogg/<name>.ogg`); the lossless WAVs are release attachments and are not used. URLs are pinned to the reviewed commit, not to `main`.
