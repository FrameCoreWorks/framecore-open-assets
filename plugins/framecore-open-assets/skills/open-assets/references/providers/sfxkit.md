# SFX Kit (Wyzowl, CC0 video sound effects)

Sources: [repository](https://github.com/wyzowl/sfx-kit) (README, LICENSE, `sounds.json`) at commit `92780e7ab0cdfb557497a988089c47f46e8c7412` (pinned), also published on [Hugging Face](https://huggingface.co/datasets/wyzowl/sfx-kit). Read 2026-11-18.

320 sound effects made for videos, animations and interfaces: whooshes, swishes, swipes, reverse whooshes, risers and fallers, impacts, cinematic hits, booms and sub drops, pops, appear/vanish, shape changes, interface clicks, keyboard typing, writing and drawing, phone, mechanical, notifications, money, logo stings, shimmers and more. CC0 1.0: commercial use, no credit required. Per the README every sound is synthesised by code (no recordings or other libraries), made with an AI model directed by Wyzowl and checked by ear before release.

No account or key. One request reads `sounds.json` (about 0.6 MB): id, name, category, tags, use and avoid notes, duration, sync point and loudness. Query words are matched against id, name, category, tags, description and use notes; a record whose id starts with a query word ranks first. Each record is one WAV (largest about 1.4 MB). The records carry the use/avoid notes and the sync point, which help place a whoosh or hit on a cut.
